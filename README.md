# ⚡ Prince | Premium Developer Portfolio

> An ultra-minimalist, mobile-first personal portfolio website crafted to showcase Android development projects, skills, and services with zero clutter.

[![Live Demo](https://img.shields.io/badge/Live_Demo-View_Site-111111?style=for-the-badge&logo=github)](https://ryxcoder.github.io)

## 🌟 About This Project

This portfolio is engineered with a strict "Mobile-First" approach, ensuring a flawless user experience across all smartphone screens before scaling up to desktop. It heavily relies on clean typography, strategic whitespace, and buttery-smooth staggered animations to deliver a high-end, premium feel without the overhead of heavy frameworks.

## ✨ Key Features

* **📱 Mobile-First Architecture:** Pixel-perfect layout optimized specifically for smartphone displays.
* **🎭 Premium Animations:** Custom CSS staggered fade-up entry animations for a cinematic load effect.
* **⚡ Blazing Fast:** Built entirely with vanilla web technologies. Zero bloat, zero dependencies.
* **☁️ Auto-Deployed:** Seamlessly hosted on GitHub Pages with continuous deployment.

## 🛠️ Tech Stack

* **Structure:** Semantic HTML5
* **Styling:** CSS3 (Flexbox, Custom Keyframe Animations)
* **Logic:** Vanilla JavaScript (ES6)
* **Typography:** [Inter Font](https://fonts.google.com/specimen/Inter) by Google Fonts
* **Hosting:** GitHub Pages
